# 🚀 NovaOS v7.5 Omni Edition

[Русская версия (Russian Version)](README_RU.md)

**NovaOS** is a full-featured graphical operating system (GUI) for the **CC: Tweaked / ComputerCraft** Minecraft mod. It features a window manager, rednet messaging, media player with DFPWM audio support, games, and built-in utilities.

---

## ⚡ Quick Installation in Minecraft

Run this command on your **Advanced Computer** terminal in-game:

```bash
wget run [https://raw.githubusercontent.com/majnkraftmdzava-lang/NovaOS/main/install.lua](https://raw.githubusercontent.com/majnkraftmdzava-lang/NovaOS/main/install.lua)
```

> ⚠️ **Note:** Make sure HTTP API is enabled on your server (`http.enabled = true` in ComputerCraft config).

---

## ✨ Features

- 🪟 **Window Manager:** Drag & drop windows, minimize (`_`), maximize (`□`), close (`X`), and layered click-through protection.
- 💬 **Rednet Messenger:** Send direct or broadcast chat messages to other computers via modem.
- 🎵 **Audio Player:** 8-bit chiptunes and native support for full `.dfpwm` / `.wav` audio streams.
- 🐍 **Snake Game:** Built-in Snake game with local high score saving (`snake_hi.txt`).
- 🧮 **Built-in Apps:** Calculator, Notepad (saves to `note.txt`), File Explorer, Task Manager.
- 🎨 **Customization:** Multiple desktop color themes and system settings.

---

## 🔊 High-Quality Audio Setup

To listen to full original audio tracks (like **Lord Verity**), connect a **Speaker** to your computer and download the audio file via terminal:

```bash
wget [https://remote.craftos-pc.cc/music/content/yL2v3Fux.wav](https://remote.craftos-pc.cc/music/content/yL2v3Fux.wav) lord_verity.dfpwm
```
