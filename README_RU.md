# 🚀 NovaOS v7.5 Omni Edition

[English Version](README.md)

**NovaOS** — это полноценная графическая операционная система (GUI) для мода **CC: Tweaked / ComputerCraft** в Minecraft. Включает многозадачность, оконный интерфейс, аудиоплеер, мессенджер по Rednet и комплект встроенных приложений.

---

## ⚡ Быстрая установка в игре

Введите эту команду в терминале **Advanced Computer** в игре:

```bash
wget run [https://raw.githubusercontent.com/YOUR_USERNAME/NovaOS/main/install.lua](https://raw.githubusercontent.com/YOUR_USERNAME/NovaOS/main/install.lua)
```

**Альтернативный способ установки (если не работает первый):**
```bash
pastebin run xa2q9LMz
```

> ⚠️ **Важно:** В конфигах сервера должен быть включен HTTP API (`http.enabled = true`).

---

## ✨ Возможности NovaOS

- 🪟 **Оконный менеджер:** Сворачивание (`_`), разворачивание (`□`), закрытие (`X`), перетаскивание мышью и защита от случайных прокликов сквозь окна.
- 💬 **Rednet Messenger:** Сетевой чат для отправки личных и общих сообщений между компьютерами.
- 🎵 **Audio Player:** Воспроизведение 8-битных мелодий и поддержка полных аудиопотоков формата `.dfpwm` / `.wav`.
- 🐍 **Snake Game:** Игра «Змейка» с сохранением лучших результатов.
- 🧮 **Приложения:** Калькулятор, Блокнот с сохранением в `note.txt`, Проводник файлов, Диспетчер задач.
- 🎨 **Кастомизация:** Смена тем рабочего стола и гибкая настройка.

## 🔊 Воспроизведение треков высокой четкости

Для прослушивания оригинальных треков (например, **Lord Verity**) подключите **Speaker** и скачайте аудиофайл прямо в ОС:

```bash
wget [https://remote.craftos-pc.cc/music/content/yL2v3Fux.wav](https://remote.craftos-pc.cc/music/content/yL2v3Fux.wav) lord_verity.dfpwm
```
